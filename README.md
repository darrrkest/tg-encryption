# Шифратор: Telegram Mini App без бэкенда, статические ключи

Один экран: вводите текст, нажимаете «Зашифровать». Приложение шифрует текст открытым ключом, тут же расшифровывает результат закрытым ключом и сравнивает с исходным. Шифротекст показывается только при совпадении, иначе выводится ошибка и копирование блокируется.

- **Алгоритм:** libsodium `crypto_box_seal` (X25519 + XSalsa20-Poly1305), то же, что `SealedBox` в PyNaCl.
- **Формат:** шифротекст в стандартном base64.
- **Сеть:** CSP `connect-src 'none'` запрещает странице любые сетевые запросы.

## Структура

```
index.html        разметка и CSP
keys.js           статические ключи ← замените на свои
app.js            логика
style.css         стили (подстраиваются под тему Telegram)
vendor/sodium.js  libsodium-wrappers 0.7.15, собранная в один файл
tools/crypt.py    CLI: keygen / encrypt / decrypt (pip install pynacl)
```

## Ключи

В `keys.js` лежит демонстрационная пара. Сгенерируйте свою:

```bash
pip install pynacl
python tools/crypt.py keygen
```

и вставьте значения в `keys.js`. При запуске приложение проверяет, что `privateKey` соответствует `publicKey`, и при ошибке не даёт шифровать.

### ⚠️ Закрытый ключ на странице публичен

Всё, что лежит на GitHub Pages, может скачать любой, кто знает адрес. С `privateKey` в `keys.js` расшифровать ваш шифротекст сможет кто угодно. Поэтому:

- если проверка нужна только как самотест, а секретность не важна, оставьте как есть;
- если шифротекст должен оставаться секретом, поставьте `privateKey: ""`. Проверка отключится (приложение так и напишет), шифрование продолжит работать. Проверять тогда можно у себя: `python tools/crypt.py decrypt <закрытый_ключ>`.

## Деплой на GitHub Pages

1. Создайте репозиторий и загрузите в корень всё содержимое папки.
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту страница доступна по адресу `https://<логин>.github.io/<репозиторий>/`.

## Подключение к Telegram

1. @BotFather → `/newbot`.
2. @BotFather → `/mybots` → ваш бот → **Bot Settings → Configure Mini App → Enable Mini App**, укажите URL страницы.
3. Приложение открывается кнопкой «Open» в профиле бота или по ссылке `https://t.me/<имя_бота>?startapp`.

Код бота запускать не нужно.

## Работа с компьютера

```bash
echo "секрет" | python tools/crypt.py encrypt <открытый_ключ>
echo "<шифротекст>" | python tools/crypt.py decrypt <закрытый_ключ>
```
